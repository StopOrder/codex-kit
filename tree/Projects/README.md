# ~/Projects — 결과물의 집

**실제로 만드는 것들이 사는 곳.** 앱·사이트·분석·문서·공모전 제출물은 전부 여기 층 아래에 폴더 하나로 만든다.
도구(에이전트)는 `~/workspace/`에 산다.

## 5층 — 번호는 카테고리

`~/workspace/`의 층 번호가 역할 순서인 것과 달리, 여기 번호는 **지금 벌이는 일의 갈래**다. 공통점은 04 하나 —
끝난 것은 아카이브로 내려간다.

| 층 | 무엇이 사는가 |
|---|---|
| `00-research/` | 리서치. `<YYYY-MM>/w<N>/<날짜>-<slug>/` 꼴로 주차별 정리 |
| `01-main/` | 지금의 주력 프로젝트 하나. 층 폴더가 곧 그 프로젝트 repo여도 된다 |
| `02-hackathon/` | 해커톤·공모전·경진대회 출전작. 대회당 폴더 하나 |
| `03-personal/` | 개인 프로젝트 |
| `04-archive/` | 끝난 것. 되살릴 때만 꺼내 해당 층으로 되올린다 |

## 규칙

- 최상위에는 층 폴더 5개와 이 README만 산다. 새 프로젝트는 층 아래에.
- 카테고리가 애매하면 지레 정하지 말고 사용자에게 묻는다.
- 프로젝트 폴더의 설정(`AGENTS.md`)은 `$project-init`으로 만든다.
- 밖에 앉은 에이전트가 여기로 산출물을 써넣는 프로젝트는 루트 `AGENTS.md`에 받는 `OUT_SLUG`를 적어 둔다.
