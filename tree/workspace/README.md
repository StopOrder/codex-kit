# ~/workspace — 도구의 집

**프로젝트를 만드는 도구가 사는 곳.** 에이전트 폴더·인프라·실험이 여기 산다. 결과물은 `~/Projects/`에 산다.

## 5층 — 번호는 역할 순서

| 층 | 무엇이 사는가 |
|---|---|
| `00-workflow/` | 일하는 절차 자체에 관한 것 — 규약 문서, 체크리스트, 템플릿 |
| `01-infra/` | 머신·계정·설정을 다루는 것 — 환경 설정 기록, 설치 스크립트, 백업 |
| `02-sandbox/` | 만드는 중인 에이전트와 실험. 새 에이전트 폴더는 **항상 여기서 시작**한다 |
| `03-agents/` | 몇 번 실제로 써서 도메인이 정해진 에이전트. `02-sandbox`에서 **사용자 지시로만** 승격 |
| `04-archive/` | 끝난 것. 되살릴 때만 꺼내 올린다 |

## 규칙

- 최상위에는 층 폴더 5개와 이 README만 산다. 새 폴더는 층 아래에.
- 에이전트 폴더 하나 = 도메인 하나. 폴더에 앉으면 그 `AGENTS.md`와 `.agents/skills/`가 그 에이전트다.
- **에이전트 폴더에 산출물을 남기지 않는다.** 결과는 `~/Projects/<층>/<프로젝트>/<OUT_SLUG>/`로. 상세는 `~/.codex/AGENTS.md` §2.
- 에이전트 폴더의 뼈대는 `$agent-init`으로 만든다.
