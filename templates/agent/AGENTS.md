이 폴더에는 산출물을 남기지 않는다. 결과는 `~/Projects/<층>/<프로젝트>/<OUT_SLUG>/<회차-또는-주제>/`로 쓴다.
프로젝트를 지정받지 못했으면 파일을 만들기 전에 묻는다. (전역 규약 `~/.codex/AGENTS.md` §2가 이 문서보다 우선한다.)

## 장비

| 경로 | 무엇 |
|---|---|
| `.agents/skills/<이름>/SKILL.md` | 이 에이전트의 절차. `$<이름>`으로 부른다 |
| `tools/` | 이 에이전트가 쓰는 스크립트. 실행 전 `tools/README.md`를 본다 |
| `assets/` | 여러 프로젝트에서 두 번 이상 실제로 쓴 재료만 |
| `vendor/<repo>/` | 남의 repo. **고치지 않는다** — 필요하면 `tools/`에 래퍼를 쓴다 |
| `docs/` | 이 에이전트를 만든 기록 — 설계, 함정 노트, 장비용 HANDOFF.md |
